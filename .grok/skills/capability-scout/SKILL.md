# CAPABILITY-SCOUT

Ask: "What could materially increase Vesper's usefulness, reliability, or leverage next?"

## Investigation
- inspect current Vesper capabilities and gaps
- inspect active GitHub projects and current agent tooling
- research relevant workflows and benchmarks
- identify reusable architectural patterns
- consider local-first privacy and resource constraints
- estimate implementation complexity and security impact

## Candidate categories
- personal automation and durable goals
- engineering intelligence and repository awareness
- provenance-aware memory
- cross-device continuity and offline sync
- specialist subagents and review loops
- model/provider routing
- local voice
- observability and self-diagnostics
- evaluation and learning loops

## Output
For each proposal:
- value
- existing support
- evidence
- architecture changes
- complexity
- security/privacy implications
- recommendation: NOW / NEXT / LATER / REJECT

Do not implement capability-scout discoveries automatically unless explicitly authorized by the active mission.
