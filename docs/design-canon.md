# Vesper visual canon

Vesper should feel like a sophisticated intelligence inhabiting the computer —
modern, precise, elegant, protective, personal. Not a chatbot skin. Not Mortis.
Not NEXUS. Not Grok.

## Identity

- Futuristic but restrained
- Calm by default, powerful on demand
- Slightly mysterious
- Recognizable without the word "Vesper" on screen

## Materials

- Near-black field `#0a0a0b`
- Surface `#121214`, elevated `#1a1a1e`
- Parchment foreground `#e8e6e1`
- Cool muted `#8b9aa8`
- One accent: cool gray `#c4cdd6` on dark, never purple, never gold, never neon
- Status: quiet green / amber / red only on badges

## Type

- Display: Instrument Serif
- Body: Outfit
- Mono: IBM Plex Mono, for ids, states, logs

## Geometry

- Concentric radii: card larger than the control it contains
- Hairline borders, one shadow recipe at most
- No glassmorphism soup, no particle fields, no gradient blobs

## State language

Idle, listening, thinking, searching, executing, waiting for confirmation,
delegating, completed, warning, error, offline, synchronizing.

Motion communicates state. It does not decorate.

## Workspaces change the surface, not the intelligence

Gaming, Development, Streaming, Mortis — same Vesper, different operational
emphasis. Mortis canon stays Mortis.

## Do not

- Copy Grok's visual identity
- Clone Mortis (ancient / lore-heavy / oppressive)
- Treat NEXUS telemetry as Vesper chrome
- Use emoji as iconography
- Let generated mockups redefine canon
